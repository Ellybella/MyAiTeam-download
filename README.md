# My AI Team

ChatGPT · Claude · Gemini를 한 회의실에 모아 서로의 답을 읽고 토론하게 하는 **무료 Windows 프로그램**입니다.
A free Windows app where ChatGPT, Claude and Gemini read each other's answers and debate in one meeting room.

## ⬇️ 다운로드 / Download

**[최신 버전 받기 → Releases](../../releases/latest)**

`MyAITeam-Setup-v버전.exe`를 받아 실행하면 설치됩니다. (Windows 10/11)
Download and run `MyAITeam-Setup-v<version>.exe`. (Windows 10/11)

> "Windows의 PC 보호" 화면이 뜨면 **[추가 정보] → [실행]**을 누르세요. 인터넷에서 받은 프로그램이라 처음에 한 번 뜨는 정상 화면입니다.
> If "Windows protected your PC" appears, click **[More info] → [Run anyway]**.

## 필요한 것 / Requirements

| 방식 | 필요한 것 |
|---|---|
| 웹 채팅 (복사·붙여넣기) | 무료 계정이면 충분 |
| Gemini (무료 API) 자동 토론 | Google 계정 + Google AI Studio 무료 API 키 |
| Claude (Claude Code) 자동 토론 | Claude Pro/Max 구독 |
| ChatGPT (Codex) 자동 토론 | ChatGPT Plus 이상 구독 |

프로그램 자체는 무료이며 결제 기능이 없습니다. 각자의 AI 계정으로 동작합니다.
